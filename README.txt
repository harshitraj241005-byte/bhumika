# Bhumika Proposal Website

## GitHub Pages par upload karne ka easiest tareeka

1. Is ZIP ko extract karo.
2. GitHub par apna repository open karo.
3. Repository ke purane files delete/replace karke is folder ke saare files upload karo.
4. `index.html` root folder me rehna chahiye.
5. Repository → Settings → Pages.
6. Source me `Deploy from a branch` select karo.
7. Branch `main` aur folder `/(root)` select karke Save karo.
8. Kuch minutes baad website live ho jayegi.

## Included
- Anywhere first touch/click → song starts
- Moving Yes button (5 escapes, then catchable)
- No button → first tap swaps, second tap disappears
- Yes → final romantic screen
- 9 floating Bhumika photos
- Main center photo + message
- Mobile-first responsive layout
